# LMU V1.4.2 업데이트

- 공식 게임 패치: V1.4.2
- 공식 BoP: V1.4.2, 2026-09-22
- 프로젝트 검토일: 2026-09-23
- 셋업 상태: 368개 모두 `REVIEW_V142` (실주행 재검증 필요)

## 공식 근거

- 패치 노트: <https://guide.lemansultimate.com/hc/en-gb/articles/17713037697807-V1-4-2-Update-1-4-Patch-2>
- BoP 안내: <https://guide.lemansultimate.com/hc/en-gb/articles/17714158179727-Balance-of-Performance-1-4-2-Update-September-2026>
- BoP 원본: `data/reference/bop/LMU_BOP_1.4.2_Marked-up.pdf`

## 셋업 영향

- 공식 패치 노트는 모든 트랙의 BoP 조정을 명시한다. COTA의 Hypercar 스틴트 에너지도 줄었다.
- LMGT3 브레이크 패드의 최적 온도 범위 상한이 확대됐다. 브레이크 온도와 덕트 설정을 다시 확인해야 한다.
- Daytona와 Laguna Seca에서는 Hypercar Hard 타이어가 제거됐다. Daytona Hypercar 타이어에는 진동 완화를 위한 변경이 적용됐다.
- Daytona의 Real Road 프로필이 수정됐고, 전 트랙의 트랙 리밋 판정이 재검토됐다.

## 배포 데이터

`data/reference-setups/2026-09-v1.4.2/`에 368개 `.svm` 후보와 매니페스트를 생성했다. Daytona·Laguna Seca·Circuit de la Sarthe의 69개는 V1.4.1 후보 파일에서, 나머지 299개는 2026-07 참조 파일에서 이어받았다. 각 파일에는 패치·BoP·재검증 상태를 기록했으며 튜닝 파라미터는 보존했다. 게임이 적용하는 BoP 값이나 타이어 선택을 `.svm` 인덱스로 추정해 변경하지 않았다. 웹은 이 후보 파일을 다운로드한다.

## 검증 우선순위

1. COTA Hypercar: 짧아진 스틴트 에너지와 연료/가상 에너지 표시 확인
2. Daytona·Laguna Seca Hypercar: 사용 가능 타이어와 장거리 거동 확인
3. 전 트랙 LMGT3: 브레이크 온도와 덕트 설정 확인
4. 전 트랙 차량별 BoP 변화에 따른 기준 랩과 타이어 스틴트 기록
