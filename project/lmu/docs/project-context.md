# LMU Setup 프로젝트 컨텍스트

## 목적

Le Mans Ultimate의 LMGT3 및 Hypercar용 안정형(stable) 기본 레이스 셋업을 체계적으로 관리하고 배포한다. 사용자는 차량과 트랙을 고른 뒤 신뢰할 수 있는 셋업을 찾고, 게임에서 바로 불러올 수 있는 `.svm` 파일 또는 ZIP 패키지로 받을 수 있어야 한다.

## 제품 범위

- 차량 클래스: LMGT3, Hypercar
- 데이터: 차량, 트랙, 세팅 파라미터, 버전/패치/BoP 정보, 출처와 검증 상태
- 생성: 구조가 검증된 `.svm` 템플릿을 기반으로 한 파일 생성과 일괄 ZIP 내보내기
- 웹: 차량·트랙·조건·성향 필터, 셋업 비교, 개별/묶음 다운로드, 변경 이력
- 운영: 공식 패치 노트, 커뮤니티/포럼, 검증 주행 결과를 근거로 데이터 갱신

## 안정형 셋업 원칙

안정형 셋업은 절대적인 한 랩 최고 기록보다 일관성, 타이어 관리, 연료 구간 전체의 예측 가능성, 커브와 고속 구간에서의 신뢰감을 우선한다. 극단적인 차고·댐퍼·윙·전자장비 값은 피하고, 차량 고유 특성과 트랙 특성을 반영한 보수적 기준점을 제공한다.

## 데이터 운영 원칙

- 원본 파일은 `data/raw/`에 보존하고, 변환된 산출물은 별도 경로에 둔다.
- 각 셋업은 차량, 클래스, 트랙, 게임/패치 버전, 생성일, 검증 상태, 출처를 가진다.
- `.svm` 포맷은 알려지지 않은 필드를 임의로 수정하지 않는다. 생성기는 템플릿을 보존적으로 변환하고 결과 파일을 검증한다.
- 패치 또는 BoP 변경은 기존 데이터를 덮어쓰지 말고 버전 및 변경 사유를 기록한다.

## 현재 가져온 자료

- `data/raw/LMU_안정형_전체_셋업_DB_2026-07.xlsx`
- `data/reference-setups/2026-07/` — LMGT3·Hypercar 트랙별 안정형 `.svm` 참조 자료 및 `manifest.csv`

## 권장 구현 순서

1. 스프레드시트 탭·열과 `.svm` 바이너리/텍스트 구조를 조사한다.
2. 차량, 트랙, 셋업, 파라미터, 릴리스의 정규 스키마를 문서화한다.
3. import/validate/export 스크립트와 재현성 테스트를 만든다.
4. 웹 앱의 검색, 비교, 다운로드 흐름을 구현한다.
5. 관리자용 편집·검증·릴리스 흐름을 추가한다.
